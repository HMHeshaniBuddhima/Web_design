# Web Design Project - Bright Future College

This is a responsive web application created for the Web Design assessment.

## 🚀 Features
- **Responsive Layout:** Works smoothly on mobile, tablet, and desktop screens.
- **Interactive Elements:** Simple JavaScript functionalities included.
- **CSS Animations:** Smooth transition effects.
- **Data Table:** Organized structure for displaying school details.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📁 Project Structure
- `index.html` - Main HTML document
- `style.css` - Custom styling and layout styles
- `script.js` - JavaScript interaction
- `images/` - Image assets used in the project
